# Гайд: как самому нарисовать шрифт

Здесь всё, что нужно, чтобы править шрифт самому — без меня.

---

## 1. Что это за шрифт

Файл **`Font.png`** — это лист тайлов: **16 тайлов в ширину × 12 в высоту**, каждый тайл **10×10 пикселей**. Именно его `Font_Inserter.py` вставляет в ROM.

Каждый тайл — одна буква. Формат 4bpp (16 цветов), но фактически используются два:

| Индекс | Цвет (RGB) | Что это |
|---|---|---|
| **6** | `248,248,248` (белый) | **тело буквы** |
| **2** | `96,96,96` (тёмно-серый) | **тень** — на 1px вниз-вправо от тела |
| 0 | `0,0,0` | пусто (прозрачно) |

**Это главный секрет:** у оригинала каждая буква — белое тело + серая тень снизу-справа. Без тени буква выглядит «плоской» и не совпадает с латиницей. Мои скрипты добавляют тень **автоматически** — ты рисуешь только белое тело.

---

## 2. Какой тайл = какая буква

| Тайлы | Что |
|---|---|
| 0–32 | заглавные А–Я |
| 33–65 | строчные а–я |
| 66–89 | пусто (не используется) |
| 90–99 | цифры 0–9 |
| 100–125 | латиница A–Z |
| 126–151 | латиница a–z |
| 152–179 | знаки препинания |

Тайл 0 = А, тайл 1 = Б, … тайл 32 = Я. Тайл 33 = а, … тайл 65 = я.

Редактируешь только **0–65** (кириллицу). 90–179 — оригинальная латиница, не трогай.

## 3. Правила рисования (чтобы было в одном стиле с оригиналом)

### Базовая линия (главное!)
Тайл 10×10, строки нумеруются **0…9 сверху вниз**.

- **Заглавные:** тело в строках **1–8**. Низ буквы = **строка 8**. Строки 0 и 9 пустые.
- **Строчные:** тело в строках **3–8**. Низ = **строка 8**.
  - Выносные вниз (р, у, д, ф, ц, щ) опускаются до **строки 9**.
  - Выносные вверх (б, ф, точки у ё, крючок у й) поднимаются до **строк 1–2**.

Если низ у тебя не на строке 8 — буква «поплывёт» относительно остальных.

### Толщина штриха
- **Стебли (вертикальные):** 2px (`##`).
- **Горизонтальные перекладины:** 2px (две строки).
- **Изгибы (верх/низ округлых букв):** 1px (`###` на верхушке, не залитый прямоугольник).

### Ширина
- Строчные: **5px** (широкие — 6–7px).
- Заглавные: **5–7px**.
- Широкие буквы (Ш, Щ, Ж, Ю, Ф, М, м, ш, щ, ж): **7–8px**.

Ширина считается автоматически — рисуй как надо, `build_widths.py` сам замерит.

### Примеры (символ `#` = белое тело)

Заглавная «О» (как оригинал):
```
..........
.###......
#####.....
##.##.....
##.##.....
##.##.....
#####.....
.###......
..........
..........
```

Строчная «о»:
```
..........
..........
..........
.###......
#####.....
##.##.....
##.##.....
#####.....
.###......
..........
```

## 4. Как рисовать (простой путь — мои скрипты)

1. **Экспорт** — получи редактируемую картинку (увеличенную в 8 раз, с сеткой и номерами тайлов):
   ```
   python export_font.py
   ```
   → появится **`Font_edit.png`** (1280×960). Каждая буква — квадрат 80×80.

2. **Рисуй** в любом редакторе (Paint, GIMP, Aseprite, Photoshop):
   - **Чёрным** (`#000000`) — тело буквы.
   - Белым — пусто.
   - Серые рамки и номера — служебные, их не трогай (при импорте игнорируются).
   - Один «пиксель» в Font_edit.png = квадрат 8×8. Можно приближать (Ctrl+колесо).

3. **Импорт** — перенести обратно в `Font.png` (чёрный → белое тело + автотень):
   ```
   python import_font.py
   ```

4. **Пересборка ROM** — одной командой (ширины + шрифт + патчи + перевод):
   ```
   python rebuild.py
   ```

Готовый ROM — **`Insert/TPL_translation.gba`**, запускай в эмуляторе.

---

## 5. Как рисовать напрямую (Aseprite, продвинутый путь)

Если умеешь в Aseprite — можно править `Font.png` напрямую (индексированная палитра сохраняется). Правила те же, но учти:

- Рисуй телом **индексом 6** (белый).
- Тень **индексом 2** (серый) — сам рисуй её на 1px вниз-вправо от тела.
- После правки: `python build_widths.py` → `printf 'y\n\n' | python Font_Inserter.py` → пересборка.

Но проще пользоваться `export_font.py` / `import_font.py` — тень добавляется сама.

---

## 6. Частые ошибки

- **Низ буквы не на строке 8** → буква «плывёт» выше/ниже соседей.
- **Забыл тень** (рисуешь напрямую) → буква плоская, не в стиле латиницы.
- **Буква шире 8px** → наезжает на соседнюю.
- **Слишком жирно** (сплошные 2px везде) → выглядит «жирной». Изгибы делай 1px.
- **Случайно стёр/закрасил серую рамку или номер** — не страшно, импорт их игнорирует.

---

## 7. Как вернуть мои буквы, если что-то сломал

Мои текущие нарисованные буквы живут в `build_font.py` (словарь `CYR`). Если испортил `Font.png` — пересобери из него:

```
python build_font.py
python rebuild.py
```

Это вернёт буквы к моему последнему состоянию.
